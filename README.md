# מחולל QR עם לוגו

מחולל קודי QR פשוט ונוח, המאפשר ליצור קוד QR מקישור או מטקסט ולהוסיף לוגו במרכז הקוד.

## תכונות

- יצירת קוד QR מקישור, מספר טלפון או טקסט חופשי.
- העלאת לוגו מהמכשיר והצגתו במרכז קוד ה-QR.
- שינוי גודל הלוגו.
- בחירת צבע הקוד וצבע הרקע.
- שימוש ברמת תיקון שגיאות גבוהה (H) לשיפור הסיכוי לסריקה גם עם לוגו במרכז.
- תצוגה מקדימה של הקוד שנוצר.
- הורדת הקוד כתמונה באיכות גבוהה בפורמט PNG.
- ממשק רספונסיבי המותאם למחשבים ולטלפונים.
- עיבוד מקומי בדפדפן: הטקסט והלוגו אינם מועלים לשרת.

## שימוש

1. פותחים את [מחולל ה-QR](https://sh770.github.io/qrlogo/).
2. מזינים קישור או טקסט.
3. בוחרים לוגו מהמכשיר (לא חובה).
4. מתאימים את גודל הלוגו ואת צבעי הקוד והרקע לפי הצורך.
5. לוחצים על **יצירת קוד QR**.
6. לוחצים על **הורדת QR כקובץ PNG** כדי לשמור את התמונה.

## פרסום באמצעות GitHub Pages

כדי לפרסם את הפרויקט:

1. נכנסים להגדרות המאגר: [Settings → Pages](https://github.com/sh770/qrlogo/settings/pages).
2. תחת **Build and deployment** בוחרים **Deploy from a branch**.
3. בוחרים את הענף `main` ואת התיקייה `/ (root)`.
4. שומרים באמצעות **Save**.

לאחר פרסום מוצלח, האתר יהיה זמין בכתובת:

https://sh770.github.io/qrlogo/

## טכנולוגיות

- HTML

- [QRCode.js](https://github.com/davidshimjs/qrcodejs) ליצירת קודי QR בדפדפן.

## פרטיות

הפרויקט פועל בצד הלקוח. הטקסט והלוגו שנבחרו מעובדים בדפדפן ואינם נשלחים לשרת על ידי קוד הפרויקט. טעינת ספריית QRCode.js מתבצעת דרך CDN ולכן נדרש חיבור לאינטרנט בעת טעינת האתר.
